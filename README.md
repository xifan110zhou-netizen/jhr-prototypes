# JHR 产品原型库

团队产品方案的交互演示与评审入口。

## 在线访问

- [原型库首页](https://xifan110zhou-netizen.github.io/jhr-prototypes/)
- [假期方案](https://xifan110zhou-netizen.github.io/jhr-prototypes/leave-plan/)
- [考勤结果与异常处理](https://xifan110zhou-netizen.github.io/jhr-prototypes/attendance-results/)

## 原型目录

| 原型 | 目录 | 内容 |
|---|---|---|
| 假期方案 | `leave-plan/` | 六个管理模块、员工端、请销假、批次余额和审批联动 |
| 考勤结果与异常处理 | `attendance-results/` | 补卡规则、打卡记录、异常结果、员工补卡与导入步骤的静态点击原型 |

## 后续新增原型

1. 在根目录新建独立文件夹，例如 `scheduling/`。
2. 将原型入口命名为 `index.html`，图片、脚本等使用相对路径。
3. 在根目录 `index.html` 增加入口，并更新此目录表。
4. 提交到 `main`，GitHub Pages 会更新网页。

原型链接结构：`https://xifan110zhou-netizen.github.io/jhr-prototypes/目录名/`。

## 访问与数据

此仓库及网页公开可访问，仅放可公开展示的原型。当前均使用演示数据，原始原型截图未上传。

假期 Demo 的操作只保存在各自浏览器中，不与他人共享，不连接真实审批、人事或通知系统。后续不同原型应采用独立的本地存储键。

考勤 Demo 采用固定示例数据，所有操作只展示页面与反馈，不进行业务数据处理。
